# Публикация и стоимость

Проверено по официальной документации 31 октября 2026 года.

| Компонент | Бесплатная квота |
|---|---|
| Cloudflare Workers Free | 100 000 запросов/день, 10 мс CPU на вызов |
| D1 на Workers Free | 5 млн прочитанных и 100 000 записанных строк/день; 5 ГБ суммарного хранения |
| Workers AI | 10 000 neurons/день; это не количество сообщений |

Источники: https://developers.cloudflare.com/workers/platform/pricing/ · https://developers.cloudflare.com/d1/platform/pricing/ · https://developers.cloudflare.com/workers-ai/platform/pricing/

При превышении бесплатной квоты операции могут перестать работать. Платный тариф не включать без разрешения владельца. Часть AI-моделей требует оплаты; выбранную модель и доступ аккаунта нужно проверить реальным вызовом перед включением. 100 попыток FAQ в день — дополнительный предел приложения, он не гарантирует укладывание в neurons. Домен покупать не требуется: для MVP достаточно workers.dev. Ожидаемая стоимость инфраструктуры — $0/месяц при использовании Free и в пределах квот, это не обещание бесплатной работы без ограничений.

## Что осталось получить от владельца

1. Вход Cloudflare и GitHub (вкладки уже открыты). Создание аккаунта с принятием условий выполняет пользователь либо отдельно подтверждает этот шаг.
2. Подтверждено: Karate klub Budo, Keldrimäe tn 9, Tallinn; от 3 лет; первые 2 тренировки бесплатно. Родитель сначала подтверждает интерес, затем тренер назначает время. Реальные слоты и постоянные цены пока не указаны.
3. Telegram-бот через официальный @BotFather; секрет передаётся непосредственно в хранилище Cloudflare, не в чат и не в GitHub.
4. Тестовый chat ID владельца и опубликованные сведения об обработке данных до live-запуска.

## Порядок развёртывания после входа

```sh
npm ci
npm test
npx wrangler login
npx wrangler d1 create karate-growth-ai
```

Скопировать возвращённый `database_id` в `wrangler.jsonc`, заменив `REPLACE_AFTER_DATABASE_CREATION`. Не создавать базу повторно, если она уже создана.

```sh
npm run db:remote
npx wrangler secret put ADMIN_TOKEN
npx wrangler secret put WEBHOOK_SECRET
npx wrangler secret put TELEGRAM_BOT_TOKEN
npx wrangler secret put TEST_CHAT_ID
npm run deploy
```

Секреты ADMIN_TOKEN и WEBHOOK_SECRET должны быть разными случайными значениями не короче 32 байт. Вводить их через защищённые интерактивные запросы, не аргументы команды. TEST_CHAT_ID берётся из настоящего сообщения владельца боту. В production .dev.vars не загружается. DEMO_MODE оставлять `true`, AI_ENABLED — `false` до проверки. CI ниже запускает только тесты, не публикует.

## Telegram

Официальный API: https://core.telegram.org/bots/api#setwebhook

До установки webhook вызвать `getMe`, убедиться, что токен относится к нужному боту. Не печатать URL с токеном в логи. Установить `setWebhook`: URL `https://<фактический-worker>.workers.dev/telegram`, `secret_token` равен WEBHOOK_SECRET, `allowed_updates=["message"]`, `max_connections=1`. Проверить `getWebhookInfo`: правильный URL, отсутствие ошибок. Не сбрасывать накопленные сообщения без отдельного решения.

Далее владелец отправляет `/start` боту и проходит весь путь. Проверить CRM, бронь, реальный ответ Telegram, повтор webhook и отказ при неверном secret. Тест назначения двух заинтересованных родителей на последнее место должен дать одну бронь. До назначения заявка должна оставаться в статусе ожидания. Только после этого бот считается работающим в облаке.

## AI и live

Внести реальные факты в CLUB_FACTS; подтвердить язык. Включить AI_ENABLED, проверить русский и украинский FAQ, неизвестный вопрос, сбой модели и дневной лимит. Перед live заменить тестовый текст /privacy на утверждённые владельцем сведения и политику, а затем убрать DEMO_MODE. Автопубликации не включаются: для каждой площадки потребуются права и поддерживаемый официальный API.

## GitHub

Использовать предоставленный владельцем репозиторий https://github.com/tsvetkoffalexandr-hue/Karate (публичный). Загружать только исходники, тесты и lockfile. `.dev.vars`, `.wrangler/`, node_modules и временные конфиги не загружать. Не использовать существующие unrelated репозитории. После добавления Cloudflare-интеграции возможно автоматическое развёртывание из main; сейчас оно не настроено.
